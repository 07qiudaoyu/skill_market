上传技能


      

        


        
        

          
          

            
    
              
  1. zip 根目录必须包含三个文件：README.md、SKILL.md、skill.json（放在子文件夹里审核不通过）。
    2. 
              
  2. 大小限制：压缩包 ≤ 50MB；解压后全部内容合计 ≤ 100MB。
    3. 
              
  3. skill.json 一致性：表单里的 slug、版本号、分类、标签、简介，必须与 skill.json 内的 name、version、category、tags、description 逐项完全一致（标签不看顺序，看集合）。
    4. 
              
  4. SKILL.md 头部：文件必须以 --- 开头，frontmatter 里的 name 与 slug 一致、description 与简介一致；name 长度 1–64，description 长度 1–1024；文件需 UTF-8 编码。
    5. 
              
  5. 分类与标签只能使用下方对照表中的值（写入 skill.json 的是 slug，小写）。
    6.
